# Bare-epub-Generator
A combination of my python epub/docx handling scripts hotglued together with a GUI slapped on the front for ease of use. 
It generates a super basic epub from which you can produce a completed small clean/small epub.

**The epub it generates is not complete and ready for distribution.**
**You will need to be futz with the epub to make it ready!**
**I use Calibre for this process.**

**Use this entirely at your own risk!**

## What it does
Tab 1 uses style simplifer to go through a document and...
- Set the document to one unified language (if it's been through editors in different countries word can have single words set to the wrong language)
- Remap, strip or leave in place existing document styles (if you're using the epub generation, Heading1 is used for chapter titles)
- Retain bold/italic formatting
- Unhides hidden text
- Optionally:
  - strip underline/strikethrough/all-caps/small-caps/superscript/subscript
  - Deletes empty paragraphs
  - Strips metadata
  - Highlights single characters with isolated formatting (e.g. and accidentally italicised comma) and allows you to strip that formatting
- Produces a clean docx file with only the styles selected and the above changes applied.

Tab 2 uses docx2epub to take a document (usually the one just generated by the simplifier tab, but you can feed it a regular uncleaned doc) and...
- Allows you to optionally configure the author/title information
- Allows you to add a cover jpg
- Allows you to add custom stylesheets/fonts/page style css files
- Allows you to add font files to your epub (you will need to manually add the code for these to your fonts.css)
- Renders out a bare epub with these files in it for you to produce a small / clean epub with neat formatting
  -The epub will have bare <p>some text</p> for each paragraph, and use spans for other text styles
- Generates message bubbles based on a subset of css from April's epub styles project (https://github.com/april/epub-styles/tree/main/css) if you have the appropriate tags in your docx (see notes below) 
- Optionally generates SVG files for any sections of message bubble text (see notes below)
Has some basic file safety error/overwrite checking

## What it does not do:
  - Check that you've to included the fonts listed in your css files (just checks fonts.css and asks you for files, it's up to you to do the matching)
  - Add fonts added to your font.css (it just includes the font files in the output epub file)
  - Intelligently check your stylesheet to see if you have existing definitions for styles - it will prepend its added span tags to your stylesheet for you to fix
  - Insert the code for the cover image - you'll have to do that manually, but it puts the file in the epub file
 
## The Message Bubbles and SVG bit
If your docx file contains the style 'messages' the epub will be output with message-them and message-me rows using some very basic tags in the document:
- In the messages block it will scan for days, times and names.
- It will ask you which person in each conversation should be allocated to the message-me column.
See the example file to see how the tags in the messages style should be used.

If you select generate SVG images it will also generate some basic SVG text bubbles for use in documents. A separate SVG is generated for each set section of messaging text - they are named for the chapter they're in.

## Requirements
Python, obviously.
The following packages: customtkinter python-docx EBookLib beautifulsoup4
(You can install these by typing: pip install customtkinter python-docx EBookLib beautifulsoup4 on a command line if you have python installed)
